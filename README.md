**GET /api/search**

Функция ищет в БД postgres различные объекты с использованием полнотекстовоно поиска, траграмм. На текущий момент реализован поиск по ГАР справочнику.

Параметры:
```
        q - поисковая строка 2 < q < 100
        принимает строку в «поисковом» синтаксисе (как в Google) по следующим правилам
        1. Слова через пробел — логическое И
            кот собака → кот И собака
        2. Кавычки — точная фраза
            "черный кот" → слова подряд: «черный кот»
        3. Минус перед словом — исключить слово
            кот -собака → кот, но не собака
        4. OR — логическое ИЛИ
            кот OR собака → кот ИЛИ собака
        5. Круглые скобки — группировка условий
            (кот OR собака) -мышь → (кот или собака), но без «мышь»
```
Возвращает:
```
        [ {
            "data": [ { набор объектов характерных для данной области поиска } ],
            "number_results":0,                                                     
            "scope":"gar",
            }
        ]
```
Если область поиска проверялась, и ничего не найдено, в массив попадет пустой ответ с пустым массивом data, number_results = 0. Таким образом можно понять где производился поиск. Данные в массиве data отсортированы в порядке релевантности. Дополнительной сортировки нет смысла делать.

        scope = gar (поиск по адресному справочнику ГАР)

        data = [ {
            "objectid": bigint          # 1086332 - уникальный идентификатор объекта в ГАР
            "full_address": text        # "Ростовская область, город Таганрог" - полный адрес
            "object_type": text         # <6 вариантов типов обьекта>
                address - любая часть адреса (улица, область, город, поселок)
                apartment - квартира
                carplace - место под машину
                house - строение
                room - комната
                stead - земельный участок
            "object_attr": {}             # дополнительные параметры именно для этого типа объектов (только для address / house)
                "leveltype": text         # address: тип объекта как он называеться в ГАР (русское имя)
                "apartmentbuilding": text # houses: 1 - признак того что данное строение в ГАР имеет флаг многоквартирного дома
                "cadastrnum": text        # houses: кадастровый номер
                "postindex": text         # houses: почтовый индекс
                "housetype": text         # houses: тип объекта как он называеться в ГАР (русское имя)
            rank: numeric               # ts_rank_cd(search_vector, q) as rank ориентироваться на него точно не надо, так как
                                        # запрос проходит несколько подзапросов с различными векторами. это не общий вектор.
                                        # он формируеться в каждом подзапросе
            }
        ]
